 # Hikaru Doll Gallery Site

 ## DEMO
🔗[Hikaru Doll Gallery Site](https://hikarudoll.xsrv.jp/gallery-site/)  
 ※ポートフォリオ用の架空サイトです。実在するクリエイターのギャラリーではありません。
 ## 使用技術
 HTML / CSS / JavaScript / PHP / WordPress 
 ## 制作内容
- コーディング/WordPress実装 
- WordPressオリジナルテーマ
- レスポンシブ対応
- プラグイン（ACF）によるカスタムフィールド実装
- プラグイン（ContactForm7）によるメールフォーム実装
- アクセシビリティを意識したマークアップ
## 工夫したこと
デザインは海外のセレクトショップ（ECサイト）を参考に、レイアウトの勉強を目的として作成しました。  
将来、画像を大量に投稿していく事を想定し、画像圧縮系のプラグイン（EWWW Image Optimizer）を入れました。
Aboutページの人物画像はO-DANで提供されている素材を使用しています。その他の作品画像は全て自身で撮影・編集しました。
